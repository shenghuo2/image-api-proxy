## 负载测试

在 `worker/` 下运行 `npm run test:load`，结果写入 `artifacts/load.json`。GitHub Actions 也会保存 `worker-load-metrics` 测试附件。

测试使用 workerd、SQLite 和 alarm，模拟一天内均匀到达的 1000 次生成：100 次同步、900 次持久化任务，每次结果约 2 MiB。包括状态查询、下载和过期清理；上游为模拟服务，不消耗 NovelAI 点数。

| 指标 | 测试结果 |
| --- | ---: |
| 完成生成 | 1,000 |
| API 请求 | 2,803 |
| Alarm 执行 | 900 |
| 读取行数 | 479,287 |
| 写入行数 | 35,834 |
| 完成后结果占用抽样峰值 | 36.00 MiB |
| SQLite 大小抽样峰值 | 37.23 MiB |
| workerd 宿主进程峰值 RSS | 329.91 MiB |

SQL 计数包括索引和删除，alarm 操作按每次一行估计，不含初始化账本。每完成 20 次生成采样一次存储量，因此表中数值不包含执行中的容量预留，也可能遗漏短时峰值。

请求数需另加用户轮询和管理页面访问。进程 RSS 包含数据库、运行时和测试框架，无法据此推算线上 isolate 内存；当前运行时也未提供可靠的堆用量测量。
