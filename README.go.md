# Go / Docker 版

Go / Docker 版在 [`main`](https://github.com/shenghuo2/image-api-proxy/tree/main) 分支维护，支持图库和长期归档。

- [部署与使用](https://github.com/shenghuo2/image-api-proxy/blob/main/docs/USAGE.md)
- [开发指南](https://github.com/shenghuo2/image-api-proxy/blob/main/docs/DEVELOPMENT.md)

此分支中的 Go 源码用于行为对照。运行 Docker 版请使用 `main`，以便配套使用带图库的前端和 Docker 配置。
